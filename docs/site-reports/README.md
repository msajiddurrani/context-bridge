# Site DOM Investigator Reports Directory

This directory stores real DOM investigator reports captured from live AI platform sessions (Claude, ChatGPT, and Gemini).

## Security & Privacy Guarantee
All reports generated by the Context Bridge DOM Investigator tool (accessible via the extension popup's **"Copy full site report"** button on the Diagnostics tab):
- **Contain ZERO chat text, prompts, code snippets, or user credentials**.
- Strip all node text, attributes containing personal data, and conversation bodies.
- Collect strictly structural DOM metadata:
  - Container tags, layout hierarchy, and element class structures.
  - Active input box element signatures and contenteditable properties.
  - Data attributes (`data-testid`, `data-message-author-role`, ARIA roles) used for deterministic adapter selectors.
  - SPA URL transition events and navigation timing.

## Structure
- `chatgpt-report.md`: Verified live DOM audit report for ChatGPT (`chatgpt.com`).
- `claude-report.md`: Verified live DOM audit report for Anthropic Claude (`claude.ai`).
- `gemini-report.md`: Verified live DOM audit report for Google Gemini (`gemini.google.com`).
